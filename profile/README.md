# Applied AI Source Code Repository

Welcome to the official code repository for **Applied AI**, a Minnesota 501(c)(3) nonprofit building leaders in artificial intelligence. Founded in 2019, we're the largest AI community in the Upper Midwest, with 9,000+ members. Our mission is to empower people of all ages with the skills and knowledge to apply AI to real-world challenges.

**Website:** [appliedai.mn](https://www.appliedai.mn)

## Repository Purpose

This repository is the central hub for code and projects our community builds together. It includes:

- **Project Codebases:** Source code for community projects, demos, and experiments.
- **Collaborative Tools:** Scripts, utilities, and tools developed by our contributors.
- **Educational Resources:** Examples, tutorials, and hands-on materials for learning AI in practical ways.

---

## Getting Started

1. **Explore the Projects:** Browse the repository to find a project or tool that interests you.
2. **Read the Documentation:** Each project folder has its own README with setup instructions, usage details, and contribution guidelines.
3. **Set Up Your Environment:** Follow the project's instructions to install dependencies and run it locally.
4. **Contribute:** See the [Contributing Guidelines](CONTRIBUTING.md).

---

## How to Contribute

- **Code:** Fix bugs, add features, or improve existing projects.
- **Documentation:** Improve READMEs, tutorials, and examples.
- **Community Support:** Share ideas, give feedback, or help fellow contributors in Slack and at meetups.
- **Workshops & Talks:** Host or participate in training sessions and workshops.
